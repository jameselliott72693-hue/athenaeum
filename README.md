# The Athenaeum

Seat a table, paste a subject, and read what the chairs can actually support from their books.

The shelf lives in `data/`: one file for the tables, and one file per thinker. Choose a table first. A named table stays inside that tradition. The open table is the exception: you may seat chairs from any tradition there, up to the same limits, and each chair keeps a tradition label. The present shelf is still there. Three political tables sit beside it, and so do a classical Christian table, an ancient philosophy table, and a Victorian critics table. Three more are single traditions as well: a classical Chinese table with the Dhammapada, an Enlightenment table, and an American founding table. A roster is the `thinkers` list on that table in `data/tables.json`, and the page seats from that list. A new chair also needs a file in `data/thinkers/` and an id in the top-level `thinkers` list.

A line in quotation marks is taken from a public-domain text. Every other card is a summary. A Modern read is a paraphrase stored with the card, labeled as such, and a later live reply can put its own text on the turn. Chairs with nothing relevant sit out. A later chair speaks only from a card, or a searched passage, that shares a topic or a term with what was already said. A searched passage is quoted whole, marked “from the full text,” and cited to its book and place. Curated cards win a tie. Brass notes are the room’s framing, not a quotation. Sound is on until you mute it. Pause, step, and speed stay in this browser. A follow-up can go to the whole table or to one chair. Bookmarks, seatings, and full sittings are kept in this browser and can be exported as JSON. A sitting can also be shared as a link in the address bar. If the link would be too long, the page says so and leaves the text and PDF downloads in place. Print includes the citation links. Search the books looks across the current table, or every table. A search result is not a citation until a chair speaks it. Compare asks the same subject at two tables’ usual chairs and lists only the topics and lines those chairs cited. A reading path walks a few passages already in the public-domain books on that table. Progress stays in this browser. Putting a passage to the table seats its author and uses the passage as the brief; it does not seat anyone else. Each table also shows the years and place already recorded for its chairs, and a few plain facts about who taught, read, or answered whom. A missing line is not a claim that nobody read anybody. None of those facts is a quotation.

Thinkers whose books are still in copyright stay on their cards. The list is in `data/books/manifest.json`. To rebuild the corpus and the search index from the raw files named in that script:

```
node scripts/build-books.js
```

The script reads plain text from `BOOK_RAW` (default `/tmp/pg`), strips the Project Gutenberg boilerplate, writes cleaned passages to `data/books/text/`, and writes one BM25 index per thinker to `data/books/index/`. The page loads an index only when a search or a sitting needs that thinker. `BOOK_ONLY=hume,kant` rebuilds just those thinkers and leaves the other index files in place.

The new tables stay inside one tradition each. A few limits are on purpose. Mencius is Book I only: Wilson's anthology marks the other books omitted or does not reach them before the Shi King. Voltaire is Fleming's 1901 dictionary, volume 1, A through Apparition. Hamilton and Madison are only the Federalist papers this Gutenberg text labels with that one name; the three papers labeled "MADISON, with HAMILTON" are in neither index. Washington is the Farewell Address, not the whole volume of messages. Zhuangzi stops before Giles's chapter XXXIII and the subject index. On a narrow screen the list of tables is one column, and the fields stay at a size you can type in.

Jewish thought and the Reformation were looked through again, and they are still not tables. A new table needs six authors, each with a public-domain English book of his own, and a quoted line has to be that book's words. Friedländer's 1910 Guide (Gutenberg 73584) is Maimonides. Whiston's Josephus is a history beside that, not a second philosopher's book. Philo on Gutenberg is Norman Bentwich's biography (14657), not Philo's works. Halevi's diwan there is in German (61327), and the Kuzari appears only as excerpts in Halper's anthology (61386). Husik's history (27821) retells Saadia, Bahya, and the others; it is not their books. Spinoza is not seated to fill a gap. On the Reformation side, Allen's 1813 Institutes (45001) is Calvin, and Luther has the 1915 Philadelphia Works (31604) and the 1921 Bente and Dau Large Catechism (1722). That is two authors with their own books. Hooker's Laws was not found as its own ebook; 13139 is Walton's life of him. Tyndale's Obedience was not found as its own ebook; 70856 is a biography. Knox's History (48250) is Cuthbert Lennox's 1905 revision, marked a twentieth-century edition. Melanchthon's Augsburg Confession (275) names no translator and no year of the English, so it was left off. Three chairs would not make the table.

Tonight's docket is a separate page, `docket.html`. It reads `docket/index.json`, newest night first, and opens the newest night unless the address names one. A night's address is `docket.html?night=YYYY-MM-DD` (a `#night=YYYY-MM-DD` hash opens the same night). If that address names a night that is not in the list, the page keeps the address and says the night is not on the docket. A chair portrait is taken from the sitting. A path written as `assets/name.svg` is loaded from `images/name.svg`. Each index entry has a date, a label, and whichever files that night has: `file` is the sittings (`docket/YYYY-MM-DD.json`, optional until they are built) and `report` is the discourse report (`docket/YYYY-MM-DD-report.json`). To publish a night, add the report file, add the sittings file when it is ready, and put the entry at the top of the `nights` list. The page shows the report for every night that has one. A story with a sitting links to it, and that sitting links back. A night with a report and no sittings yet shows the report and says the sittings are coming. On a night's page, Mark as read keeps that night in this browser under `athenaeum:docket:read`. The night menu shows a check for a read night and a dot for an unread one, with a count of nights still unread. The newest night still opens when the address does not name one. Quotation marks on a sitting are drawn only from quotes the sittings file marks verified. The report's own wording is shown as plain text. A chair's name opens that chair's page, `docket.html?chair=` followed by the name. The page lists every sitting the chair joined on a live night, the verified quotations with work and location, and the chairs they most often agree or disagree with. A shared sitting listed in `docket/agreements.json` counts as an agreement. A split on one of those sittings that puts the two names on different sides counts as a disagreement. A chair with a shelf id still links to that thinker's page.

Thinkers has its own page, `thinkers.html`, linked from the site navigation. It lists every chair in `data/thinkers/` and every name seated on a live or archived night. The shelf file supplies the years, the place, the note, and the works. The night files supply the sittings and the verified quotations, and each sitting links to `docket.html`. A name the shelf does not use stays a separate dossier, with only what the sittings recorded. A shared sitting listed in `docket/agreements.json` counts as an agreement. A split on one of those sittings that puts the two names on different sides counts as a disagreement. The matrix and the list under it are those pairs. The minimum is a number of shared sittings, and it can be lowered to one. Era in the filter is the century of the first year on the record, or the century the record already names.

Saved highlights live in this browser under `athenaeum.reader`, version 1. On a sitting you can select a passage, a Modern read, or report text and save it, with a color and a note. Each verified quotation also has Save quote. The words are stored themselves, so a night can leave the menu and the passage remains. Folders, including Unsorted, can be labeled, reordered, and searched from Saved in the site navigation. Export writes JSON, plain text, or Markdown, and import reads the JSON back. Saved can also compile a commonplace book from every passage, or from the folders you choose, arranged by folder, by thinker, or by the work, sitting, or encounter it came from. A title and an epigraph are optional. The book can be previewed and printed, or saved as PDF from the browser, and the same book can be downloaded as HTML or Markdown. The words are the ones already saved. A Modern read stays marked as a paraphrase. A film, a song, or a poem saved from Further encounters uses the same folders, and its kind is `film`, `song`, or `poem`.

Further encounters are in `data/encounters.json`, version 1. Each work has a type, a title, a creator, a year, a short note in the room's own words, one or more theme ids, and a link. A film may also name an MPAA rating when one is known. A public-domain poem may include its text and the edition that text was taken from. A song never includes lyrics. The controlled themes are `justice`, `mortality`, `freedom-order`, `faith-doubt`, `duty`, `love`, `truth`, `power`, `mercy`, `good-life`, `dignity`, `exile`, and `conscience`. A sitting may name one to three of those ids in an optional `themes` array. Nights already published are mapped in `data/encounter-map.json` instead, so their text is left as it was. If a sitting has neither, the page infers tags from the question, and if that finds nothing the section stays hidden. The browse page is `encounters.html`. How a weekly edition should add `themes` is in `build_sittings.md`.

The night page has a search box. It looks through every live night in `docket/index.json` for a thinker, a story, or a verified quotation, and a result opens that night at the sitting.

A news source may name an archived copy. The optional `archived` field is an http or https URL on that source in the report, and the same field may sit on a verified quotation. The page keeps the original link and, when the field is a usable URL, adds an archived link beside it. A missing or unsafe value adds nothing.

A verified quotation links to its public-domain text when the data has a URL. The optional `passage_url` field, when it is an http or https URL, is the exact place. Otherwise the link uses `source_url`. If neither field is a usable URL, the quotation has no link. Do not invent one.

A night may name an audio edition. The optional `audio` field on its index entry is a path under the docket, such as `audio/YYYY-MM-DD.mp3`, and the file itself is `docket/audio/YYYY-MM-DD.mp3`. When the field is present the night shows a player. A night that omits the field needs no audio file.

Those audio editions are also the podcast. After a weekly edition's MP3 is committed and its index entry names it, regenerate the feed:

```
node scripts/build-podcast.js
```

The script reads `docket/index.json` and, when that file exists, `docket/archive.json`. A night is an episode only when it names an audio file that is actually committed at `docket/audio/YYYY-MM-DD.mp3`, and the sittings file `docket/YYYY-MM-DD.json` is present. It writes `docket/podcast.xml` and one chapter file, `docket/audio/YYYY-MM-DD.chapters.json`, per episode. The enclosure length is the MP3's size in bytes. The duration is measured from the file: the Xing or Info frame count when the MP3 carries one, otherwise a walk of the audio frames. It is not estimated. Chapter times divide that measured length by the character length of the introduction (title, date, subtitle, and the short edition's own note) and of each short-edition sitting (headline, question, setup, the moderator, and the chairs' turns). The first chapter is Intro. Each sitting chapter is that sitting's headline and question. If the sittings file has an `audio_chapters` list, those start times are used instead. Each entry needs an `id` (`intro`, or a short-edition sitting id) and a `start` in seconds, beginning at 0. An MP3 that already has ID3 chapter frames is used the same way when `audio_chapters` is absent. Commit the feed and the chapter files with the audio. The public feed address is `https://jameselliott72693-hue.github.io/athenaeum/docket/podcast.xml`.

When a night is older than 30 days, archive it instead of deleting it. Take its entry out of the `nights` list in `docket/index.json` and put that same entry in `docket/archive.json` (newest first), or leave the entry in the index and set `"archived": true`. Leave `docket/YYYY-MM-DD.json` and `docket/YYYY-MM-DD-report.json` in place. The night drops off the night menu. The archive page lists it, and `docket.html?night=YYYY-MM-DD` still opens it. Then run `node scripts/build-agreements.js` so the agreement file still counts a night that moved to the archive. If that night has an audio file, run `node scripts/build-podcast.js` as well so the podcast feed follows the move. Do not delete the sitting file or the report file.

Open the folder through a local server, or through the hosted site. A file opened directly cannot load the shelf.
